# 搜题助手鸿蒙版 · 对齐方案

> 目标：**鸿蒙版与安卓版在界面和功能上无太大差异**（对齐安卓 `v0.5-floatwindow-modules`）。
> 技术实现换用鸿蒙原生能力，算法与交互逻辑沿用安卓已验证方案。
> 文档日期：2026-08-09

---

## 1. 对齐目标与原则

| 维度 | 做法 |
|---|---|
| 功能 | 与安卓 v0.5 已实现功能一一对应；未开发的（读屏/AI 搜题）同安卓保持占位禁用 |
| 界面 | 复刻安卓的配色、圆角、文案、布局：主题绿 `#1D9E75`、红 `#E24B4A`、页面底 `#F7F7F7`、卡片圆角 12dp、浮窗 4 模块结构 |
| 算法 | LCS 最长公共子串、txt 三格式解析、OCR 回调序列号防乱序、浮窗总高公式 —— 全部沿用安卓 |
| 平台能力 | 悬浮窗/截屏/OCR/存储 换用鸿蒙原生接口（见 §4 换型表） |

## 2. 功能范围（对齐清单）

> 依据：安卓 `MainActivity.kt` + `FloatWindowService.kt` 现有实现

### 2.1 主页（`Index.ets`，对标安卓 HomeScreen）
- **搜题方式卡片「浮窗搜题」**：状态圆点三态（运行中 / 未开启 / 未授权）+ 主按钮三态（授权悬浮窗权限 / 关闭服务（需重新授权）/ 启动服务）+ 未勾选题库警告（⚠ 未勾选任何题库 / ✓ 已勾选 N 个题库用于搜题）+ 启动失败错误提示
- **占位入口（同安卓置灰/点击无功能）**：读屏搜题、扫描搜题、AI 搜题
- **题库管理 4 图标**：📁 智能导入（可点）、📚 题库总览（可点）、🌐 公共题库（禁用）、🔗 远程导入（禁用）
- **设置项**：权限管理、OCR 引擎（中文离线识别）、显示 OCR 识别范围（调试红框开关）、关于（v1.0）

### 2.2 浮窗（`FloatPage.ets`，对标安卓 buildStandbyUi）
**4 模块垂直布局（严格裁剪互不侵入）：**

```
┌ ① 顶栏 (28dp) ────────────────────────────┐
│ ●状态字  [手动搜题] [扫描开关] [—老板键]     │
├ ② 绿框识别区 (默认150dp，可resize) ────────┤
│    虚线框(绿) + 右下角 ◢ resize 手柄        │
├ ③ OCR 原文 (状态文字，无内容时高度=0) ────┤
├ ④ 匹配结果区 (60-180dp 动态) ────────────┤
│    卡片: 题干 + 选项 + ✔答案 + 来源        │
└───────────────────────────────────────────┘
```

- **绿框 resize**：宽 100-720dp、高 20-400dp；浮窗总宽 = max(360dp, 绿框宽 + 8dp)
- **浮窗总高公式**（沿用安卓）：`topBar(28) + topSpace(0) + 绿框高 + OCR状态高 + ScrollView(60~180)`
- **扫描三态**：`🔓授权并扫描 → ⏸暂停 → ▶继续`（暂停保留采集会话，恢复免重授权）
- **老板键**：`—` 缩成 28dp 红 `+`（可拖动、背景透明、保持识别会话），点 `+` 恢复
- **手动搜题模式**（顶栏切换）：输入框 + 搜索按钮 + 结果列表（复用 §4 搜索链路）
- **调试**：设置里开「显示 OCR 识别范围」→ 浮窗显示红色边框（真实识别范围）

### 2.3 题库管理三页（鸿蒙需新增，对标安卓 Import/Overview/BankDetail）
- **手动导入页**：选文件 → 后台解析 → 命名对话框（含文件名校验、已识别 N 题、字数覆盖率彩色提示 ≥90 绿 / ≥70 橙 / <70 红，<60 拒绝导入）
- **题库总览页**：Tab「手动导入 / AI 导入」、勾选激活题库（绿底高亮）、右上角「确认(N)」、分享（导出 txt 走系统分享）、删除
- **题库详情页**：题目列表（题干 + 选项 + 答案绿字 + 删除单题）

### 2.4 数据与存储
- Bank / Question 模型、激活题库集合、Preferences 存储 —— **鸿蒙 `QuestionBank.ets` 已实现 ✅**
- 导入源格式：txt（三排版）优先；docx / pdf(文字版) / xls 后续（对标安卓 Importer.kt）

## 4. 关键技术换型表

| 能力 | 安卓做法 | 鸿蒙做法（ArkTS） | 备注 |
|---|---|---|---|
| 悬浮窗 | `WindowManager.TYPE_FLOAT` | `window.createWindow(TYPE_FLOAT)` | ✅ 已实现 |
| 采集题目 | MediaProjection + VirtualDisplay + ImageReader（截屏） | **摄像头拍照**（`camera` + `ImageReceiver`，`CameraHelper` 已封装） | ⚠️ 鸿蒙第三方 App 无法截全屏（CAPTURE_SCREEN 需系统权限），**摄像头是当前唯一可行采集路线** |
| OCR | ML Kit `text-recognition-chinese` | Core Vision `textRecognition`（`@kit.CoreVisionKit`，识别中文；API 名以实际 SDK 为准） | 需封装 `OcrHelper`，内置回调序列号防乱序 |
| 题目匹配 | LCS + 完全包含 +100 | 同算法 | ✅ 已移植 |
| 存储 | SharedPreferences | `@ohos.data.preferences` | ✅ 已移植 |
| 状态同步 | SharedPreferences 500ms 轮询 | Preferences 轮询 或 `EventHub` | 主页↔浮窗状态 |
| 定时扫描 | Handler + Runnable 每 2s | `setInterval` + busy 锁 | CameraHelper 已含 2s 定时 |
| 老板键 | 悬浮窗 height 切换 + 独立小窗 | 悬浮窗 `resize` / 第二窗口 | M2 |

## 6. 里程碑

### M1 · 识别闭环（核心价值，先做）
1. 封装 `OcrHelper.ets`：pixelMap → `textRecognition` → 文本（含回调序列号）
2. `CameraHelper.onPhotoTaken` 接到 OcrHelper → `QuestionBank.search` → 回调结果
3. `FloatPage` 升级 4 模块布局 + 识别状态机（待机中→识别中→结果），结果卡片渲染（题干+选项+✔答案+来源，最佳卡片高亮，ScrollView 60-180dp）
4. 浮窗默认尺寸对齐安卓：绿框 150dp，总高 = 28+0+150+OCR状态+180

### M2 · 浮窗完整交互
5. 绿框 resize（◢ 手柄，100-720 × 20-400dp）+ 浮窗宽/高联动
6. 扫描三态按钮 + 暂停/恢复（保留采集会话）
7. 老板键（`—` 缩 28dp 红 `+`，可拖动，恢复时按公式重算高度）
8. 手动搜题模式（输入框 + 搜索 + 结果列表）
9. 调试红框开关（设置联动）

### M3 · 题库管理 UI
10. 导入页（选文件→解析→命名→覆盖率验证）
11. 总览页（Tab + 勾选激活 + 确认 + 分享 + 删除）
12. 详情页（题目列表 + 删除单题）
13. 主页全面对齐（§2.1 全部卡片与状态）

### M4 · 收尾

16. 开发笔记 / 踩坑记录补写（对齐安卓文档习惯）

### M5 · 进阶（与安卓同步节奏）

## 7. 风险与卡点

| 风险 | 说明 | 应对 |
|---|---|---|
| **悬浮窗权限** | `SYSTEM_FLOAT_WINDOW` 需 AGC 申请（企业/特殊资质） | 现用 trial debug profile 顶着；正式发布走申请流程 |
| **全屏截取受限** | 鸿蒙第三方 App 无系统权限截不了别的应用屏幕 | 采集用摄像头（已绕开）；`window.snapshot` 仅能截本应用窗口，不做采集主路 |
| **相机预览在浮窗** | 预览需 XComponent，浮窗内承载 XComponent 支持性待验证 | M1 可跳过预览，直接 `PhotoOutput.capture` 定时拍照；预览失败不影响识别 |
| **OCR API 版本** | `textRecognition` 接口/模型随 SDK 版本变化（当前 modelVersion 6.1.1） | M1 先按当前 SDK 验证中文识别 + 模型下载，确认后固化 |
| **鸿蒙定时器/后台** | `setInterval` 在浮窗长期运行场景需验证保活 | 复用现有 CameraHelper 定时模式，实机验证 |

## 8. 已确认结论（供后续执行引用）

1. 采集路线 = **摄像头**（`CameraHelper` 方向正确，不需要推翻）
2. 匹配算法 = **LCS**（已移植，无需改）
3. 浮窗 = **4 模块 + 高度公式**（README 已有结构图，执行按 §2.2）
4. 首批改动文件：`OcrHelper.ets`(新) → `CameraHelper` 回调 → `FloatPage`(重写) → `FloatWindowManager`(resize)
