## 一、图标来源与设计

- **设计概念**（叮叮提供）：用多行线段表示题目内容，其中插入一个「A.」代表答题卡选项，整体要科技感、不要纯绿。
- **生成方式**：文生图 → 3D 玻璃质感（顶部镜面高光 + 深蓝黑玻璃面板）→ 多行抽象线段 + 左下角发光绿色「A.」选项气泡。
- **抠图方式**：白底重绘 + flood fill 分离背景 + defringe 去白边（圆角外全透明）。

## 三、当前项目图标现状（Codex 替换时注意）

当前 `app/src/main/res/` 用的是 **Android Adaptive Icon**：

- `mipmap-anydpi-v26/ic_launcher.xml` + `ic_launcher_round.xml`
- 背景色 `@color/ic_launcher_background` = `#1D9E75`（绿色）
- 前景 `@drawable/ic_launcher_foreground.xml`（临时画的 ¥ 符号矢量图）
- **没有** `mipmap-mdpi/hdpi/...` 位图 fallback

## 四、替换方案（二选一，建议 A）

### 方案 A（推荐）：改用普通位图图标
把交付的 6 个 PNG 放到对应目录：
```
app/src/main/res/mipmap-mdpi/ic_launcher.png        ← 48
app/src/main/res/mipmap-hdpi/ic_launcher.png        ← 72
app/src/main/res/mipmap-xhdpi/ic_launcher.png       ← 96
app/src/main/res/mipmap-xxhdpi/ic_launcher.png      ← 144
app/src/main/res/mipmap-xxxhdpi/ic_launcher.png     ← 192
```
然后删除或保留 `mipmap-anydpi-v26/` 下的 adaptive XML（保留会在 Android 8.0+ 优先用 adaptive，建议删掉或指向新图）。

> 新图标本身已经带圆角 + 透明背景，直接用最省事，形状不会再被系统二次裁剪。

### 方案 B：保留 Adaptive Icon
如果坚持用 adaptive icon，需要：
1. **前景**：把图标主体放大居中（占 108×108 viewport 的中心 72×72 安全区），去掉我们预先做的圆角（因为系统会自己裁圆角/圆形/方形）
2. **背景**：可保留绿色 `#1D9E75`，或改成深色匹配图标
3. 需要额外做一版"无圆角前景图"——如需，可让 WorkBuddy 再出

> 注意：方案 B 下，我们交付的圆角图标直接当前景会导致"双重圆角"（我们的圆角 + 系统圆角），视觉会偏小。
