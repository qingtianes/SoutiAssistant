# 搜题助手 v1.0 需求规格（PRD）

## 1. 目标
把现有功能打磨成可发布、可维护的 1.0 正式版：补齐设置中心，加入扫描搜题暂停/继续，并通过专业开发、测试、审查、文档、发布与用户验收。

## 2. 范围（全部进 1.0，不推延）

### 2.1 设置中心
主页“设置”入口进入独立设置页，包含 5 类：

1. 权限管理
   - 悬浮窗权限：显示是否已授权，点击跳系统授权页
   - 摄像头权限：显示是否已授权，点击申请
   - 通知权限：显示是否已开启，点击跳通知设置
   - 录屏权限：说明“使用时系统会弹出授权”
2. 识别与匹配
   - 最多显示结果：1 / 3 / 5 / 10，默认 10
   - 最低匹配分：0-100 滑杆，默认 50
   - 识别速度：快(500ms) / 标准(1000ms) / 省电(1500ms)，默认标准
3. 浮窗显示
   - 结果字号：小 / 中 / 大，默认中
   - 显示匹配分与来源：开，默认开
   - 绿框默认大小：小 / 中 / 大，默认中
4. 扫描搜题
   - 默认缩放倍数：1.0x / 1.5x / 2.0x，默认 1.0x
   - 取景框高度：单行 / 双行，默认双行
5. 通用 / 关于
   - 当前版本号
   - 更新日志
   - 隐私说明（OCR 本机处理、不上传）
   - 意见反馈（GitHub Issues）
   - 清空本地题库与设置（二次确认）

### 2.2 扫描搜题暂停/继续
- 在“匹配答案”与 ✕ 之间居中放置暂停按钮
- 未暂停显示“暂停”，点击锁定当前输出，按钮变“继续”
- 点击“继续”恢复实时扫描；用户可不暂停一直输出

## 3. 验收标准
- 设置项修改后立即生效，重启 App 后保持
- 暂停后结果不再变化，继续后恢复更新
- 权限项状态显示准确，点击能跳对应系统页
- 清空操作有二次确认，确认后题库与设置被清空
- 所有历史功能（浮窗/读屏/扫描/导入/匹配）回归无异常
- 用户本人真机验证通过

## 4. 非功能要求
- 隐私：OCR、截屏、摄像头画面仅本机处理，不联网上传
- 性能：不因设置读取增加明显卡顿；OCR 节流随设置生效
- 兼容：Android 8+（minSdk 26），鸿蒙卓易通可运行（录屏偶发问题暂记录）
