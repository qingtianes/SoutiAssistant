# 搜题助手 v1.0 用户验收清单

> 安装包：`app/build/outputs/apk/release/app-release.apk`（v1.0.0，正式签名）
> 验收方式：真机逐项操作，每一项通过打勾；有任何一项不通过，记录现象后停止发布。

## 1. 设置中心
- [ ] 主页点“设置”能进入设置页，返回正常
- [ ] 权限管理：悬浮窗/摄像头/通知状态显示准确，点击能跳到对应系统页
- [ ] 识别与匹配：修改“最多显示结果”后，扫描/读屏结果条数相应变化
- [ ] 识别与匹配：调高“最低匹配分”后，低分结果不再出现
- [ ] 识别与匹配：识别速度“快/标准/省电”切换后，识别刷新节奏有变化
- [ ] 浮窗显示：结果字号“小/中/大”在浮窗/读屏/扫描结果上生效
- [ ] 浮窗显示：关闭“显示匹配分与来源”后，结果卡片不再显示来源和分数
- [ ] 浮窗显示：绿框默认大小“小/中/大”在重新启动浮窗后生效
- [ ] 扫描搜题：默认缩放 1.0x/1.5x/2.0x 在进入扫描页时生效
- [ ] 扫描搜题：取景框高度“单行/双行”切换后生效
- [ ] 通用/关于：版本号显示 1.0.0；更新日志、隐私说明弹窗正常
- [ ] 意见反馈能打开 GitHub Issues 页面
- [ ] 清空本地题库与设置：二次确认后题库被清空、设置恢复默认
- [ ] 重启 App 后，所有设置保持上次修改的值

## 2. 扫描搜题暂停/继续
- [ ] “匹配答案”和 ✕ 之间出现“暂停”按钮
- [ ] 点“暂停”后，答案列表不再跳动，按钮变“继续”
- [ ] 点“继续”后恢复实时更新
- [ ] 不点暂停时，持续实时输出正常

## 3. 历史功能回归
- [ ] 浮窗搜题：授权、绿框识别、输出窗显示、拖动、最小化正常
- [ ] 读屏搜题：全屏识别、多题顺序输出、小窗拖动/关闭正常
- [ ] 扫描搜题：摄像头取景、缩放、只识别框内正常
- [ ] 题库导入：txt/docx/pdf/xls 导入正常
- [ ] 题库总览：勾选题库、查看题目、删除正常

## 4. 发布前门禁
- [ ] 单元测试通过（已自动验证）
- [ ] Lint 0 error（已自动验证）
- [ ] 正式签名 Release APK 可安装、可启动
