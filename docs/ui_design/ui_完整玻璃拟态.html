使用说明
1. 题库导入
首页「题库」→「智能导入」，选择 txt / docx / pdf / xls 文件。
导入后进入「题库总览」，勾选要参与搜题的题库。
2. 浮窗搜题
点「浮窗搜题」授权悬浮窗和录屏。
屏幕出现绿色识别框，拖动/缩放到题目上。
答案显示在独立输出窗，标题栏可拖动、可最小化。
3. 读屏搜题
点「读屏搜题」，自动全屏识别，答案按顺序显示在右上角小窗，可拖动/缩放，✕ 关闭。
4. 扫描搜题
点「扫描搜题」授权摄像头，把题目对准绿色取景框。
双指或 +/− 缩放；下方显示答案；可暂停/继续。
5. 设置
首页「设置」可管理权限、识别与匹配、浮窗显示、扫描搜题等。
