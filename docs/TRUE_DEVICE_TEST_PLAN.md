# 鸿蒙真机最终验收清单

> 前置条件：使用 DevEco 自动签名的调试 HAP，保持当前代码不变，先验证设备能力，再决定是否继续实现读屏。

## 1. 安装与首次启动

- [ ] DevEco 自动签名成功；
- [ ] HAP 安装成功；
- [ ] 首页可进入，无闪退；
- [ ] 重启应用后题库状态不丢失。

## 2. TXT 题库

- [ ] 从“我的手机/下载”选择 UTF-8 TXT；
- [ ] 显示正确题数并自动启用；
- [ ] 手动输入题干可返回题目、选项和答案；
- [ ] 停用后不参与搜索；
- [ ] 再启用后恢复搜索；
- [ ] 删除后题库、题目和启用状态同时清空。

## 3. 图片 OCR

- [ ] 图片选择器可以选择相册图片；
- [ ] `textRecognition.init()` 成功；
- [ ] 中文题干和选项能识别；
- [ ] OCR 文本可编辑；
- [ ] 搜索结果与题库答案一致；
- [ ] 无文字、模糊图、旋转图均不会闪退。

## 4. 摄像头实时扫描

- [ ] 首次相机授权后立即出现预览；
- [ ] 返回再进入仍能启动；
- [ ] 定时采集不会积累临时图片；
- [ ] OCR 输出能够连续更新；
- [ ] 暂停后画面结果锁定；
- [ ] 继续后恢复识别；
- [ ] 切后台、锁屏、返回后不会占用相机或闪退；
- [ ] 连续运行 10 分钟无明显内存增长。

## 5. 悬浮窗

当前普通构建已禁用入口，并移除 `SYSTEM_FLOAT_WINDOW` 权限请求。

- [ ] 如确有系统级签名环境，再单独验证 `TYPE_FLOAT`；
- [ ] 普通发布签名不得把静态窗口标记成搜题功能。

## 6. 读屏技术探针

- [ ] 创建 `AVScreenCaptureRecorder`；
- [ ] 系统是否弹出屏幕/窗口选择与用户确认；
- [ ] 能否在应用内取得连续图像帧，而不仅是录制文件；
- [ ] 其他应用的隐私窗口是否为黑屏；
- [ ] 停止授权后资源是否完整释放。

只有“可取得连续图像帧”通过后，才进入 OCR、分题、去重和答案排列开发；否则明确标注鸿蒙普通应用暂不支持读屏搜题。

## 7. 验收资料

测试时保留：

- 设备型号和 HarmonyOS 版本；
- 每项测试的截图或录屏；
- DevEco HiLog 中的错误码；
- OCR 不可用时的系统模块日志；
- 相机、屏幕采集权限弹窗截图。
